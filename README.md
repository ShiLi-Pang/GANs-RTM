#Deep learning preconditioned methods based on generative adversarial networks for frequency-domain reverse time migration

The main purpose of this work is to introduce an adversarial training mechanism based on 
CNN architecture to construct effective preconditioners, which are integrated with BICGSTAB 
for solving the linear systems in FRTM. This kind of methods can achieve the target accuracy 
with fewer iterations and less computational time, thereby enhancing the preconditioning effect 
and further improving the migration efficiency.
